# 🎬 IMDb Movies Data Analysis Using Python

## 📌 Project Overview

This project focuses on exploring and analyzing movie data using Python and Pandas.

The goal is to understand movie ratings, genres, runtime, voting patterns, and release years by performing data analysis on an IMDb movies dataset.

This project demonstrates practical data analysis skills, including data exploration, data cleaning, filtering, sorting, and aggregation.

## 🎯 Project Objectives

- Explore and understand the movie dataset.
- Analyze IMDb ratings across different movies and genres.
- Identify movies with the highest IMDb ratings.
- Compare average ratings across genres.
- Analyze movie runtime and genre-wise runtime.
- Explore voting patterns across movies.
- Identify genres with the highest average ratings.
- Practice data manipulation and aggregation using Pandas.
- Extract meaningful insights from movie data.

## 🗂️ Dataset Information

The dataset contains information about movies, including details such as:

- Series_Title: Movie title.
- Released_Year: Year the movie was released.
- Genre: Genre or genres associated with the movie.
- IMDB_Rating: IMDb rating of the movie.
- Runtime: Duration of the movie.
- No_of_Votes: Number of votes received by the movie.

The exact columns and number of records depend on the dataset version used in this project.

## 📊 Analysis Performed

The project explores questions such as:

1. Which movie has the highest IMDb rating?
2. Which genre has the highest average IMDb rating?
3. Which genre has the longest average runtime?
4. Which movie has the highest number of votes?
5. Which genre has the highest total votes?
6. What are the genre-wise average ratings and average runtimes?

These questions help practice data filtering, grouping, and aggregation using Pandas.

## 🧠 Skills Demonstrated

- Loading CSV files using Pandas.
- Exploring datasets using DataFrame methods.
- Selecting and filtering columns and rows.
- Sorting data.
- Handling data types.
- Grouping data using `groupby()`.
- Performing aggregations using `agg()`.
- Calculating averages and maximum values.
- Extracting insights from structured data.
